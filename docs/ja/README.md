# hako ドキュメント

[English](../en/README.md)

hako は、OpenABL で起動できる Qualcomm 機の携帯ゲーム機で Debian trixie (arm64) を動かし、
自前のアプリを載せるための環境です。今の対象機は **Retroid Pocket Mini (V1, SM8250) だけ**です。

## AI エージェントと進める

この環境は、AI のコーディングエージェント (Claude Code など) と一緒に作業することを前提に組んであります。
ビルド・実機への転送・ログの確認・画面の撮影はエージェントに任せ、人は実機を操作して結果を確かめます。

- リポジトリ直下の [AGENTS.md](../../AGENTS.md) (Claude Code は CLAUDE.md 経由で読む) に、エージェント向けの
  地図と守るべきルールをまとめてあります。エージェントはこれと docs/ を読めば作業を始められます。
- 各文書には「エージェントへの頼み方」の例を載せています。そのまま貼るか、自分の状況に合わせて書き換えて使ってください。
- 役割分担の目安:

| エージェントに任せる | 人がやる |
|---|---|
| ビルド、パッケージ化、実機への転送とインストール | SD カードの書き込み、ケーブルの抜き差し、電源操作 |
| ログ・設定・ソースの調査、修正案の作成 | ボタン・タッチ・音・見た目の確認 |
| 画面の撮影 (grim) と内容の確認 | ブートローダーやパーティションに書き込むかどうかの判断 |
| ドキュメントの更新、コミット | 公開や配布の判断 |

- エージェントには「実機で人の操作が要る確認は、手順を伝えて返事を待ってから始める」ように頼んでおくと、
  画面を見ていないときに勝手に試験が進むことがありません (AGENTS.md にも書いてあります)。

## 用語

| 用語 | 意味 |
|---|---|
| OpenABL | Qualcomm 機のブートローダー (ABL) の置き換え。SD などから Linux を起動できるようにする |
| ESP | SD の先頭の FAT パーティション。カーネル・initrd・dtb と起動エントリが入る |
| ELBE | Debian のパッケージからイメージを組み立てるツール。VM (initvm) の中でビルドする |
| bsp | Board Support Package。機種固有のものをまとめたパッケージ (`rpmini-bsp`) |
| `.app` | ランチャーにアプリを登録する小さな設定ファイル |
| dev イメージ | 開発用のイメージ。ssh・デバッグツール入り、root は読み書き可 |
